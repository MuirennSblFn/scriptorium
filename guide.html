Mode d'emploi

Ajouter un texte

Tout le contenu du site vit dans un seul fichier : data/textes.js. Pas de base de données, pas d'interface d'administration : on y écrit directement, comme dans un carnet.

I. Ouvrir le bon fichier

Dans le dossier du site, ouvre data/textes.js avec un éditeur de texte simple (Bloc-notes, TextEdit, ou idéalement VS Code / Sublime Text si tu en as un). C'est un fichier JavaScript, mais pas d'inquiétude : il n'y a rien à programmer, seulement une liste à compléter.

II. Copier un exemple

Le fichier contient déjà deux textes d'exemple. Le plus simple est de copier l'un des blocs entre accolades { ... }, de le coller juste avant le commentaire final, et de modifier chaque valeur.

// Un bloc = un texte
{
  id: "mon-nouveau-texte",       // unique, sans espace ni accent
  titre: "Le titre de mon texte",
  epigraphe: "Une citation courte, ou laisse vide.",
  personnage: "Mordren",          // voir les 5 valeurs possibles ci-dessous
  date: "an 632",
  resume: "Un résumé de deux à trois lignes.",
  image: "",                       // URL d'image, ou vide
  contenu: `
    <p>Premier paragraphe du texte.</p>
    <p>Deuxième paragraphe.</p>
  `,
},
Astuce — n'oublie pas la virgule , après l'accolade fermante } de chaque texte, sauf le tout dernier de la liste. C'est la seule règle de syntaxe à retenir.

III. Écrire le contenu

Le champ contenu accepte du HTML simple. Il suffit d'entourer chaque paragraphe de <p> et </p>. Quelques balises utiles, à réutiliser telles quelles :

<p>Un paragraphe normal.</p>

<p>Un mot en <em>italique</em>, un autre en <strong>gras</strong>.</p>

<blockquote>Une citation mise en valeur.</blockquote>

<hr>  // un séparateur orné, pour marquer une coupure

<h2>Un sous-titre</h2>  // pour un texte en plusieurs parties

IV. La catégorie

Le champ personnage sert aussi de filtre dans la bibliothèque. Il n'accepte que ces 5 valeurs exactes (respecter la majuscule) :

"Alba"
"Muirenn"
"Mordren"
"Marcus"
"Autre"   // pour tout écrit qui n'appartient à aucun des 4 personnages
Attention — une autre valeur (ex. "Mordren Reiter" ou "Camlaan") ne sera pas reconnue par les filtres et le texte n'apparaîtra dans aucune catégorie sélectionnée.

V. Ajouter des images

Le site prévoit deux emplacements pour les images. Dans les deux cas, il faut d'abord déposer le fichier image dans le dossier images/ à la racine du site (à côté de index.html).

1. L'image bandeau — celle qui illustre la carte dans la bibliothèque et qui s'affiche en haut du texte une fois ouvert. Elle se règle avec le champ image du texte, dans data/textes.js :

image: "images/alba-eglise.jpg",

Si ce champ reste vide (""), une simple initiale décorative est affichée à la place — ce n'est donc jamais bloquant si tu n'as pas encore d'image.

2. Les images dans le corps du texte — pour illustrer un passage précis. Il suffit d'ajouter une balise <img> directement dans le champ contenu, au même niveau que les <p>, à l'endroit exact où tu veux qu'elle apparaisse :

<p>Un premier paragraphe.</p>

<img src="images/alba-eglise.jpg" alt="">
<p class="img-caption">Une légende facultative, sous l'image.</p>

<p>Le paragraphe qui suit.</p>
À retenir — le chemin images/nom-du-fichier.jpg doit correspondre exactement au nom du fichier déposé dans le dossier (majuscules, accents et espaces comptent — mieux vaut les éviter dans les noms de fichiers). Formats recommandés : .jpg ou .png, idéalement compressés pour rester légers.

VI. Ajouter une bande-son

Tu peux relier un texte à un morceau, une playlist ou un album Spotify — ce que tu écoutais en l'écrivant, par exemple. Un lecteur s'affiche alors automatiquement en haut du texte, juste sous le titre.

Dans Spotify, sur le morceau (ou la playlist/l'album) souhaité : clique sur Partager → Copier le lien. Colle ce lien tel quel dans le champ spotify du texte, dans data/textes.js :

spotify: "https://open.spotify.com/track/xxxxxxxxxxxxxxxxxx",
À noter — laisse ce champ vide ("") si tu ne veux pas de lecteur pour un texte donné. Aucune inscription ni clé d'accès n'est nécessaire : c'est le lecteur public de Spotify, le même que celui qu'on retrouve intégré sur d'autres sites.

VII. Publier

Une fois le fichier enregistré, ouvre simplement index.html dans un navigateur pour vérifier le rendu. Pour le mettre en ligne comme les autres fiches (sur GitHub Pages), il suffit d'envoyer l'ensemble du dossier dans un dépôt GitHub, exactement comme pour les fiches de personnage existantes.

Rien d'autre à toucher — les pages index.html, lire.html et le style se mettent à jour automatiquement à partir de data/textes.js. Il n'y a jamais besoin de créer une nouvelle page pour un nouveau texte.
